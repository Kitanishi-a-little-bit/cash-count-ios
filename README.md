# レジと金庫

紙幣・硬貨・棒金をまとめて計算する、シンプルな現金カウントアプリです。

## 主な機能

- 日本円の紙幣・硬貨ごとに枚数を入力
- 硬貨はロール数でも入力（1本50枚）
- 金種ごとの小計と合計金額を自動計算
- レジと金庫を分けて管理
- 入力内容を端末内に自動保存

ログインやネット接続は不要です。iOS 17 以降に対応しています。

## 開発環境

SwiftUI / Xcode / XcodeGen を使用しています。
`project.yml` から Xcode プロジェクトを生成して開きます。

```sh
xcodegen generate
open CashCount.xcodeproj
```
