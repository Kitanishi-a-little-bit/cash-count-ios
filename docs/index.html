レジと金庫

紙幣・硬貨・棒金をまとめて計算する、iPhone・iPad用の現金カウントアプリです。

使い方

紙幣・硬貨の枚数を入力すると、各金種の小計と合計を自動計算します。硬貨のロールは1本50枚で計算します。「レジ」と「金庫」の入力は別々に保存されます。

保存とリセット

入力は端末内に自動保存されます。リセットすると、選択中の「レジ」または「金庫」の入力内容が消去されます。
